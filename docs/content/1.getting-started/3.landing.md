## Welcome splash

On your first visit, a **Welcome to Browzarr** dialog appears with three links:

- **Quick Start** — opens Browzarr with an example dataset (ESDC `air_temperature_2m`) already plotted
- **Documentation/Guides** — these docs
- **Follow Development** — the GitHub repository

Click **Start exploring** (or the `×`) to dismiss it for now, or **Close and don't show again** to hide it for 30 days (stored in a cookie).

## Main view

Behind the splash is the main view: the **main menu** at the top lets
you load data and configure your plot, while the **floating menu** overlays the
plot area with view and export controls.

## Main menu

::steps
### :icon{name="i-tabler-database-plus" class="icon-lg"} Select dataset

Use the `database` icon to load curated datasets, a remote Zarr or Icechunk store, or your own local files! See [Dataset loading](/menus/dataset-loading).

### :icon{name="i-tabler-variable" class="icon-lg"} Select variable

now, use the `variable` icon to select the variable you would like to see and click plot!

### Change plot type

:icon{name="i-ph-cube-light" class="icon-lg"} Cube: usually for spatio-temporal variables, `x-y-t`.

:icon{name="i-gg-menu-grid-o" class="icon-lg"} Point clouds

:icon{name="i-ph-sphere-thin" class="icon-lg"} Sphere projection

:icon{name="i-mdi-square-outline" class="icon-lg"} Rectangular projection

There some default plotting options depending on your dataset dimensions, however you could change to a different plot type if your data dimensions allow it.

### :icon{name="i-noto-v1-artist-palette" class="icon-lg"} Change Colormap

See [Colorbar](/menus/colorbar). Hover the colormap options to see how your plot will change, then click on the one you like to setup that one!

### :icon{name="i-heroicons-adjustments-horizontal" class="icon-lg"} Settings

Opens **Plot Settings** for the current plot type. See [Plot settings](/menus/plot-settings).

### :icon{name="i-ph-play-pause-fill" class="icon-lg"} Animation controls

Plays through the data along its animated dimension. Not shown for flat (2D) data.

### :icon{name="i-ph-math-operations-bold" class="icon-lg"} Apply operations

WebGPU-powered analytics (hidden while a bivariate plot is active) — see [Analytics](/menus/analytics).

::

Export the current plot parameters as JSON or as a sharable URL that reopens Browzarr in the same state.

Sets the render/performance mode: pick one of three levels (rocket, car, snail) — each step halves the render resolution for smoother interaction with very large datasets.

## Opening Browzarr from a URL

Browzarr reads query parameters on load, so a link can open a dataset directly:

- `initStore` (or `dataset`) — URL of a remote store, or a local path when served by the npm/Julia versions
- `variable`, `plotType`, and other plot/colormap settings — applied as initial state
- `reproject=true` — reproject the data on load; `export=true` — export an image on load

The easiest way to get such a link is the **Export parameters** button above; the welcome splash's **Quick Start** link is an example.
