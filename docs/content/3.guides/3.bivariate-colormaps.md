Bivariate mode encodes **two variables at once**: one maps to one color axis and the second to the other, producing a 2D color scheme. Use it to look for relationships — e.g. soil moisture vs. temperature, or chlorophyll vs. sea surface temperature.

## Enabling bivariate mode

1. Select your first variable as usual
2. In the variable panel, turn on **Bivariate Plot**
3. Pick the second variable from the selector that appears (only variables with the same shape are listed)
4. Optionally enable **Share Scale** to use a common value range for both variables
5. Click **Plot**

## Customizing the colormap

With bivariate mode active, the colormap panel shows a bivariate builder instead of the usual colormap list:

- **Presets** — ready-made schemes (e.g. *Emerald Crimson*, *Deep Ocean*, *Magma Frost*)
- **Bottom-left**, **Top-left**, **Bottom-right** — pick the corner colors yourself
- **Blend Mode** — how the two axes are mixed: `darken`, `lighten`, `multiply`, or `difference`
- **Resolution** — number of color steps per axis

In the plot adjustment panel, **Map to:** selects which of the two variables further adjustments apply to.

## Reading the bivariate colorbar

The colorbar becomes a 2D square gradient:

- The **bottom-left** corner represents the minimum of both variables
- Moving along one axis changes the first variable's color contribution
- Moving along the other axis changes the second variable's
- The swap button above the colorbar toggles which variable's ticks/labels are shown

## Export

Bivariate plots can be exported like any other plot; the exported image draws the 2D colorbar and its tick labels, which can be placed in any corner (`bottomLeft`, `bottomRight`, `topLeft`, `topRight`), and you can set a label and units per variable. See [Animation & export](/guides/animation-and-export).

::callout{icon="i-lucide-lightbulb"}
Bivariate colors are harder to read for precise values — keep the univariate colorbar nearby or mention both variables and their ranges in your figure caption.
::
