Local data works the same whether you use [browzarr.io](https://browzarr.io) or a locally served app (npm or Julia, see [Installation](/getting-started/installation)). Local data is treated just like remote data: chunks are fetched on demand from the file's location on your machine. Nothing leaves your computer.

Open the dataset modal (`database +` icon), choose the **Local** tab, and use the **Zarr** / **NC/TIFF** switch to pick the file type.

## Local Zarr

With the switch on **Zarr**, select a `.zarr` directory (standard Zarr v2/v3 layout). Stores without consolidated metadata are parsed from the directory contents.

::callout{icon="i-lucide-info"}
When you select a local Zarr folder, your browser may ask whether you want to "upload" it. That is the browser's standard wording for folder access: nothing is uploaded. Browzarr only reads the files from where they are.
::

::callout{icon="i-lucide-triangle-alert"}
Local folder selection is not supported in Safari — use Chrome, Firefox, or Edge.
::

The npm package only serves the app (optionally on a chosen port); pick your directory in the dataset modal as above:

```bash
browzarr --port 8080
```

With Julia, you can launch straight into a store by path:

```julia
using Browzarr
browzarr(; store="/absolute/path/to/zarr_file.zarr")
```

## Local NetCDF and GeoTIFF

With the switch on **NC/TIFF**, pick a single file. Accepted extensions are `.nc`, `.netcdf`, `.nc3`, `.nc4` and GeoTIFF (`.tif`, `.tiff`, `.geotiff`, `.gtif`). NetCDF files are decoded in the browser with WebAssembly (netcdf4-wasm), so most classic and HDF5-based NetCDF files work without conversion.

From Julia:

```julia
browzarr(; store="/absolute/path/to/file.nc")
```

::callout{icon="i-lucide-info"}
Use **absolute paths** when passing a `store` argument.
::

## Tips for large files

- Chunked NetCDF (HDF5) files behave much better than contiguous ones
- Use the [variable sliders](/menus/variable-selection) to subset before plotting
- Consider re-chunking to `1–10 MB` chunks for snappier interaction
