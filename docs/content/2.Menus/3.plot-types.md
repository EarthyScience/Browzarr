Open the plot type menu (**Change plot type**) from the main menu. Browzarr picks a default type based on the dimensions of the selected variable; you can switch types whenever the data allows.

| Plot type | Icon | Typical dimensions | Description |
| --- | --- | --- | --- |
| **Volume (data cube)** | `cube` | `(x, y, t)` | Interactive 3D cube; slice along any axis |
| **Sphere** | `sphere` | `(lat, lon[, t])` | Data projected onto a 3D globe |
| **Flat map** | `square` | `(lat, lon[, t])` | Rectangular 2D projection |
| **Point cloud** | `grid` | `(x, y, t)` | Each value rendered as a 3D point |

## Choosing a type

- If your variable has a **time** dimension, any spatial type can be animated
- Use **cube** to explore the full spatio-temporal structure first, then switch to **sphere**/**flat** for presentation-quality maps

## Limitations

- For 2D (flat) variables only **Sphere** and **Flat map** are offered; **Volume** and **Point cloud** are hidden
- If the selection exceeds ~30 million values, the point cloud button is highlighted with an **Expect poor performance** warning

- Sphere/flat projections require regular (or at least resolvable) lat/lon coordinates
- Very large point clouds benefit from [performance mode](/getting-started/landing#performance-mode)
