Click the `database` icon (**Select dataset**) in the main menu. The popover offers:

- **Explore Datasets** — opens the **Open dataset** modal with three tabs: **Remote Zarr**, **Icechunk** and **Local**. The Remote Zarr and Icechunk tabs include a searchable catalog plus a URL field.
- **Remote** — a quick URL input with a **Zarr / Icechunk** switch
- **Local** — a quick file picker with a **Zarr / NC/TIFF** switch

## Curated catalog

The modal ships with a browsable catalog of public datasets, split into two groups:

- **Zarr stores** — e.g. SeasFire Cube, Earth System Data Cube (ESDC), CMIP6 experiments, NASA MUR SST, ARCO-OCEAN
- **Icechunk stores** — e.g. NOAA HRRR/GFS forecasts, ECMWF AIFS, ERA5 surface reanalysis, Met Office forecasts

Each entry shows a label and a short subtitle; use the search box (**Search Zarr Stores...** / **Search Icechunk Stores...**) to filter by label or subtitle. Click one to load its metadata.

## Remote store by URL

Paste the URL of a Zarr or Icechunk store:

- **Remote Zarr** — a URL pointing at the store root (where `.zmetadata`/`zarr.json` lives), e.g. `https://s3.bgc-jena.mpg.de:9000/misc/seasfire_rechunked.zarr`
- **Remote Icechunk** — a URL pointing at the Icechunk repository

For protected Zarr stores, an authentication preset can be chosen: **None**, **Bearer**, **Basic** or **API Key**.

::callout{icon="i-lucide-shield-alert"}
The store must allow cross-origin requests from the Browzarr origin (**CORS**). If a remote store fails to load, CORS is the most common culprit — see [Remote data](/guides/remote-data).
::

## Local data

Under **Local**, use the **Zarr / NC/TIFF** switch to open data from your own disk:

- **Zarr** — select a local `.zarr` folder (folder upload is not supported in Safari; use Chrome, Firefox or Edge)
- **NC/TIFF** — a single NetCDF (`.nc`, `.netcdf`, `.nc3`, `.nc4`) or GeoTIFF (`.tif`, `.tiff`, `.geotiff`, `.gtif`) file, decoded in the browser via WebAssembly

See [Local data](/guides/local-data) for details and layout requirements.

## What you see after loading

Once a dataset is selected, Browzarr parses the store's metadata and shows the available variables. From there, continue with [Variable selection](/menus/variable-selection).
