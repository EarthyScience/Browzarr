The colorbar below the plot maps data values to colors and doubles as a control surface.

## Lower and upper bounds

You can control the lower and upper bounds of your displayed data by clicking and typing different numbers in the input boxes (extreme left and right).

### Shift values

Dragging the colorbar itself will also shift the bound values, preserving the range width. A reset icon appears above the colorbar once bounds or a color operation have been changed; click it to restore the defaults.

### Scale factor

For very large or small values Browzarr automatically applies a scale factor (power of ten) so that tick labels stay readable.

### Tick count

The **−** / **+** icons above the right end of the colorbar decrease or increase the number of ticks (between 2 and 10, default 5).

## Color operations and texture precision

The settings (gear) icon left of the colorbar (univariate mode only) opens a popover where you can:

- Enter an expression such as `abs(x)` and click **Apply Operation** to transform values before coloring. Click **?** for the list of available functions; always write numbers as floats (`50.0`, not `50`).
- Toggle between **8-bit** (default, saves memory) and **16-bit** textures for greater granularity in high-variability data.

## Colormaps

Click the round colormap button (**Change Colormap**) in the main menu. Hover the colormap options to preview how your plot will change, then click the one you like to select it. The colormap menu also lets you:

- **Search...** colormaps and filter them by **Category**
- **Flip** / **Unflip** the selected colormap
- Show or hide colormap names

## Attributes

Clicking on the variable name (at the top of the colorbar) will also display its general attributes.

## Univariate vs bivariate

By default the colorbar maps one variable. In **bivariate mode** (enabled via **Bivariate Plot** in the variable menu) two variables are mapped to a 2D color scheme; a swap icon next to the title switches which variable's bounds are shown — see [Bivariate colormaps](/guides/bivariate-colormaps).
