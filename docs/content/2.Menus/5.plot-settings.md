## Plot types

Depending on the dimensions of your variable, Browzarr offers several ways to render it:

| Type | Best for |
| --- | --- |
| :icon{name="i-ph-cube-light" class="icon-lg"} **Volume (cube)** | Spatio-temporal variables (`x-y-t`) explored as an interactive 3D data cube |
| :icon{name="i-ph-sphere-thin" class="icon-lg"} **Sphere** | Projecting data onto a 3D globe |
| :icon{name="i-mdi-square-outline" class="icon-lg"} **Flat map** | Rectangular 2D projections for classic cartographic views |
| :icon{name="i-gg-menu-grid-o" class="icon-lg"} **Point cloud** | High-density spatial data as interactive 3D points |

There are default plotting options depending on your dataset dimensions; however you can change to a different plot type if your data dimensions allow it. See the [plot types reference](/menus/plot-types) for the exact requirements.

## Plot settings panel

Open the panel with the :icon{name="i-heroicons-adjustments-horizontal" class="icon-lg"} **Plot Settings** icon in the main menu. A reset icon (**Reset visual state**) restores the defaults. The options depend on the plot type:

- **Volume** — **DDA** / **Raymarch** render method (DDA is faster and artifact-free; Raymarching interpolates for softer volumes, with an adjustable step count of 50–1000), **Transparency** (0–10), **Transparency Scale** (power applied to transparency; 1 is linear) and **Scale by clip**
- **Point cloud** — **Point Size** (0.01–2), **Scale By Value** with **Scale Intensity** (1–100), **Disable Scaling**, and **Resize Time Dimension** (0.05–5)
- **Sphere** — **Displacement Mode** (**Surface** / **Faces**), **Displacement**, **Offset Negatives** and **Displacement Resolution** (4–100)
- **Flat map** — **Flat** / **Displace** switch; when displacing: **Displacement** (0–100), **Offset Negatives** and **Rotate**

### Global settings

- **Value Cropping** — hide values outside a min/max range
- **NaN Transparency** (0–1) and **NaN Color** (not for point clouds)
- **Interpolate Pixels** (not for point clouds)
- **Masking** — set a **Mask Value** and choose a **Mask Feature**: **None**, **Land** or **Water**
- **Reprojection** — shows the native CRS (which you can set or change), and lets you enter a **Target Projection** and **Resolution**; a reset icon returns to the native projection
- **Show Borders** / **Hide Borders** — overlay country borders, drawn as **Texture** or **Lines**, with adjustable **Border Width** (0.01–0.4) and **Border Color**. Disabled if the spatial extent could not be parsed.
- **Adjust Extent** — edit the spatial extent (**Min/Max Lon**, **Min/Max Lat**) and **Lon/Lat Resolution**

## Axis cropping

For volume and point cloud plots, the **Axis Cropping** button in the plot settings opens min/max sliders for each plotted axis. Drag the handles to crop the viewed extent in time, latitude, longitude, or any other dimension.

## Camera

The navigation bar toggles between:

- :icon{name="i-cil-grid" class="icon-lg"} **Orthographic** — parallel projection, no perspective distortion
- :icon{name="i-icon-park-outline-perspective" class="icon-lg"} **Perspective** — natural depth perception

Selecting the flat map switches to orthographic automatically. Use the reset camera icon (**Reset camera view**) to return to the default view.
