## Powered WebGPU analytics

Browzarr can run computations directly on the GPU using the **WebGPU** API. This enables on-the-fly analysis of the plotted data without a server.

## Enabling WebGPU

Open the analytics panel from the main menu (`math operations` icon). If your browser supports WebGPU, computations are dispatched to the GPU automatically; otherwise the feature is unavailable.

::callout{icon="i-lucide-info"}
WebGPU is currently available in Chromium-based browsers (Chrome/Edge) and is rolling out elsewhere. See [Browser support](/reference/browser-support).
::

## Built-in operations

Common operations can be applied to the selected variable — the result is rendered back through the standard colorbar pipeline.

## Custom shaders

For full control, the built-in **shader editor** lets you write custom **WGSL** compute/fragment code:

- Templates are provided as a starting point
- A kernel visualizer helps you reason about the neighborhood your kernel operates on
- Edited shaders can be applied live to the current plot

## Result

Applied operations can be toggled on and off, so you can compare the raw variable with the computed one.
