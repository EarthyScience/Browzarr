## Powered WebGPU analytics

Browzarr can run computations directly on the GPU using the **WebGPU** API. This enables on-the-fly analysis of the plotted data without a server.

## Enabling WebGPU

Open the analytics panel from the main menu (`math operations` icon, **Apply operations**). If your browser supports WebGPU, computations are dispatched to the GPU automatically; otherwise a **WebGPU Not Available** message is shown. The panel is hidden in bivariate mode.

::callout{icon="i-lucide-info"}
WebGPU is currently available in Chromium-based browsers (Chrome/Edge) and is rolling out elsewhere. See [Browser support](/reference/browser-support).
::

## Built-in operations

Choose an **Operation**, an **Axis** to operate along, and click **Execute**. The result is rendered back through the standard colorbar pipeline.

**One variable**

- *Dimension Reduction* (3D data only): **Mean**, **Min**, **Max**, **Standard Deviation**, **Linear Slope**
- *Keep Dims*: **Convolution**, **CUMSUM**

**Two variables** — click **Use Two Variables** (3D data only) and pick a **Second Variable**:

- *Dimension Reduction*: **Correlation**, **Linear Slope**, **Covariance**
- *Three Dimensional*: **Convolution**

For **CUMSUM** and **Linear Slope**, the **Rev.** switch reverses the direction of the operation.

### Convolution

Convolution applies a **Kernel Op.** (Mean, Min, Max, Standard Deviation for one variable; Correlation, Linear Slope, Covariance for two) over a moving window. Set the kernel **Size** and **Depth** (odd numbers; Depth only for 3D data). A kernel visualizer shows the neighborhood the kernel covers.

### Chaining operations

After an operation runs, the current variable shows as **Current**, and further operations are applied to the newly generated data. The reset icon next to it returns to the original variable.

## Custom shaders

For full control, click **Open Shader Editor** to write custom **WGSL** compute code:

- Templates (**Get started with presets**) are provided as a starting point
- The editor lists the available globals (axis, kernel size/depth, input/output arrays, etc.) with their current values
