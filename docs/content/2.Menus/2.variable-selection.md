After loading a dataset, use the `variable` icon (**Select Variable**) to pick the variable you want to visualize — a **Search variable...** box filters the list — and click **Plot**.

## Variable name

Shows the variable's `long_name` if available, otherwise its name as stored in the dataset.

### Attributes

Additional information about variables can be seen by clicking on the **Attributes** badge — e.g. `units`, `long_name`, `standard_name`, fill values, and any other attributes stored alongside the variable.

### Data shape, chunk shape and chunk count

A small table shows the **Data shape** (the length of every dimension, e.g. `46 × 72 × 1440`), the **Chunk shape** and the **Chunk count**. Chunking determines how much data is fetched per request — see [Supported formats](/reference/supported-formats).

### Memory and cache

Below the table the raw and stored size of the selection is shown, along with whether it fits in the cache (**Data Will Fit** / **Selection won't fit in Cache**). If it doesn't fit, decrease the selection or expand the cache size (in MB) — increasing it too far can crash the tab, especially on mobile. **Plot** is disabled while the selection does not fit.

## Options

- **Bivariate Plot** — pick a second variable with the same shape to plot both together (see [Colorbar](/menus/colorbar)). With bivariate enabled, **Share Scale** makes both variables use a common value range.
- **Coarsen** — downsample on load. **Temporal Coarsening** and **Spatial Coarsening** take an exponent `n`; the factor applied is `2ⁿ`.
- **Compress** — compress data to save memory at the cost of slightly longer load times.

## Active dimensions

Under **Active Dimensions** a slider is shown for every plotted dimension; use them to select an appropriate range along each dimension before plotting. Dimensions not being plotted are listed under **Collapsed dimensions**. A warning appears if the same dimension is assigned to multiple axes.

::callout{icon="i-lucide-lightbulb"}
Slicing early keeps memory usage low: only the chunks that intersect your selected range are downloaded.
::

## Plot

Click **Plot** to render the selection. You can then change the [plot type](/menus/plot-settings) or adjust the [colorbar](/menus/colorbar).
